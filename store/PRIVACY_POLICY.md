# ConvoWeave Privacy Policy

**Effective date:** September 13, 2026

ConvoWeave is designed to help users capture and organize meeting information while keeping users in control of recording and stored meeting data.

## Information the app handles

In the current release, ConvoWeave may handle:

- microphone audio that you explicitly choose to record
- meeting metadata such as recording time and duration
- meeting memory that you review or create, including decisions, commitments, assumptions, and notes
- source evidence associated with accepted meeting memory

## Microphone access

ConvoWeave requests microphone permission only to provide meeting recording. Recording does not begin automatically. You must explicitly start a recording.

You are responsible for notifying meeting participants and obtaining any consent required by applicable law before recording.

## Storage and transmission

The current release stores meeting recordings and application state locally on the device. The current release does not automatically upload recorded meeting audio to a remote transcription or AI service.

If a future version introduces cloud transcription, synchronization, accounts, analytics, crash reporting, or other remote processing, this policy and the applicable App Store and Google Play privacy disclosures must be updated before that version is released.

## Sale and advertising

The current release does not sell meeting data and does not use meeting content for third-party advertising.

## Private notes

ConvoWeave distinguishes private notes from shared meeting context. Private notes are not intended to enter shared AI or team context unless the user explicitly promotes them.

## Data deletion

Because the current release stores its working data locally, users can remove application data by deleting saved information through app controls as those controls become available, or by removing the application and its local data from the device. Production release must include an accessible deletion path appropriate to every data type the app stores.

## Security

ConvoWeave is developed with automated dependency review, static code analysis, dependency auditing, and repository security controls. No system can guarantee absolute security.

## Children

ConvoWeave is intended for workplace and productivity use and is not directed to children.

## Changes to this policy

This policy will be updated when the application's data practices change. Store privacy declarations must remain consistent with the behavior of the version distributed to users.

## Contact

A public support contact and privacy-policy URL must be established before public App Store or Google Play production submission.
