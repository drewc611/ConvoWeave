# ConvoWeave 0.3.0-alpha.1

Release stage: internal alpha release candidate

App version: 0.3.0

Build number / Android version code: 2

## What is in this alpha

- Suite dashboard and meeting workspace UI
- Live capture with persistent meeting notes
- Local SQLite persistence and interrupted-capture recovery
- Decision Ledger
- What Changed / decision diff
- Commitment Radar
- Assumption Register
- Contradiction Review
- Source Proof / evidence preservation
- Private Sidecar isolation
- Preview remote-processing flow with explicit upload consent and manual fallback
- Account-sync and OAuth/OIDC boundaries in the backend/MCP architecture
- Live stateless MCP preview for Claude and ChatGPT at `https://convoweave-mcp.onrender.com/mcp`
- Claude plugin package and ChatGPT integration package

## Alpha validation boundary

This release is suitable for internal Android device testing. It is not a public beta and is not approved for App Store or Google Play production distribution.

The Android alpha artifact is a debug-signed APK built by GitHub Actions for internal QA. It is not the Play Store production artifact.

The iOS code is release-packaged but a physical-device/TestFlight build still requires Apple Developer signing and the Expo/EAS project connection.

The live MCP preview is intentionally stateless and unauthenticated. It can process host-supplied meeting content but does not expose private saved ConvoWeave account memory. Account-backed production sync remains behind OAuth/durable-storage deployment work.

## Required alpha QA

Run the Critical and High core-flow cases in `docs/DEVICE_TEST_PLAN.md` on a physical Android device, then record results using `docs/QA_BUILD_MANIFEST.md` or `docs/DEVICE_VALIDATION_REPORT_TEMPLATE.md`.

At minimum verify:

- start/stop recording and microphone-denial behavior
- live note persistence through interruption/restart
- unfinished capture recovery
- review-state recovery
- Decision Ledger, What Changed, Commitment Radar, Assumption Register and Contradiction Review
- Private Sidecar remains private unless explicitly promoted
- remote preview requires explicit upload approval
- provider/request failures present a request ID and allow manual fallback
- no provider secrets are present in the mobile build
- background recording remains disabled

## Promotion rule

Promote this release to beta only after all Critical device cases pass and High core-flow failures have an explicit release disposition. iOS/TestFlight and Google Play internal testing remain separate signed-store distribution gates.
