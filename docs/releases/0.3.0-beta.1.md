# ConvoWeave 0.3.0-beta.1

Release stage: internal Android beta candidate

App version: 0.3.0

Build number / Android version code: 3

## What is in this beta candidate

- ConvoWeave Suite dashboard and meeting workspace
- Live capture with persistent typed meeting notes
- SQLite-backed local-first meeting state
- Interrupted-capture and unfinished-review recovery
- Decision Ledger and decision lineage
- What Changed meeting-to-meeting diffs
- Commitment Radar
- Assumption Register
- Contradiction Review with source evidence
- Source Proof for durable meeting memory
- Private Sidecar with explicit promotion boundary
- Optional remote processing with explicit per-meeting upload consent
- Manual/local fallback when remote preview is unavailable
- OAuth/OIDC account-sync and MCP boundaries
- ChatGPT and Claude integration packages
- Public privacy, support, and account-deletion pages

## Automated beta qualification

Before this candidate is promoted, the repository must show green results for:

- Mobile CI
- release preflight and dependency audit
- Security CI
- CodeQL
- Android native generation and APK build
- Android emulator install and launch
- package registration and resumed-activity verification
- fatal runtime launch scan
- emulator screenshot and runtime evidence capture

## Distribution boundary

The Android beta artifact produced by GitHub Actions is a debug-signed APK for internal beta testing. It is installable outside Google Play and is not the final Play Store production artifact.

The signed App Store/TestFlight and Google Play internal-track builds remain gated on connecting the Expo/EAS project and the account-holder Apple and Google signing/submission accounts.

Physical-device QA remains required before public release. Use `docs/DEVICE_TEST_PLAN.md` and `docs/DEVICE_VALIDATION_REPORT_TEMPLATE.md` to record Android and iOS results. Critical failures are release blockers.

## Privacy boundary

- Recording begins only after explicit user action.
- Background recording remains disabled.
- Provider credentials must never be present in the mobile bundle.
- Private Sidecar notes stay outside shared context unless explicitly promoted.
- Audio upload requires a matching, unexpired per-meeting approval.
- Remote-generated proposals require human review before becoming durable memory.

## Promotion rule

This package may be used as the first internal beta candidate after the Android emulator gate passes. Public beta/store promotion still requires signed builds, physical-device validation, and completion of the account-holder release gates tracked in Issues #3, #4, and #5.
